🚀 COMO IMPLEMENTAR (3 PASSOS):
═══════════════════════════════════════════════════════════════════════

PASSO 1: Adicionar Scripts
  └─ Abra index.html
  └─ Antes de </body>, adicione:
     <script src="fp-pix-enrichment.js"></script>
     <script src="fp-pix-manager-ui.js"></script>

PASSO 2: Testar no Console
  └─ F12 (Developer Tools)
  └─ Aba Console
  └─ Digite: PIX_MANAGER.show()
  └─ Deve abrir modal

PASSO 3: Adicionar Beneficiários
  └─ No Console, adicione para cada PIX:
     FP_PIX_ENRICHMENT.addBeneficiary('1601370', 'João Silva');

❓ PROBLEMAS COMUNS:
═══════════════════════════════════════════════════════════════════════

"PIX_MANAGER não definido"
  → fp-pix-manager-ui.js não foi carregado
  → Verifique se está no index.html

"Modal não abre"
  → F12 → Console → PIX_MANAGER.show()
  → Procure erros no Console

"Dados desaparecem"
  → localStorage pode ser limpo
  → Use "Exportar" regularmente para backup

"Beneficiário não aparece"
  → Verifique código (ex: '1601370' correto)
  → Console: console.log(FP_PIX_ENRICHMENT.beneficiaries)
